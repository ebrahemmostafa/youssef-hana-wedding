# Youssef & Hana — Wedding Invitation

A one-page wedding invitation. Guests tap **Click to open**, the doors-opening video plays, and then the invitation appears with the date, venue and map link, the note about Katb El-Kitab timing, the dress code for kids, and a live countdown. Background music plays from YouTube.

Static site, no build step: open `index.html` or serve the folder (for example with GitHub Pages).
